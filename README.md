# Wine Quality Data Analysis

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) and data preprocessing using the Wine Quality dataset.

The analysis is conducted in Python using Jupyter Notebook as part of the Big Data and Energy Data Analysis course.

## Objectives

- Load and examine the Wine Quality dataset.
- Identify and handle missing values.
- Examine descriptive statistics.
- Detect and investigate outliers.
- Visualize distributions and relationships between variables.
- Analyze correlations between wine characteristics and quality ratings.
- Prepare the dataset for potential machine learning applications.

## Dataset
- The dataset that is given to you with this lab activity, is a Wine Quality dataset that can be downloaded as well from the UCI Machine Learning Repository at the following link: https://archive.ics.uci.edu/ml/datasets/wine+quality
